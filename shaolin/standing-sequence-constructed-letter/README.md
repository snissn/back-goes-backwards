# Standing sequence — constructed Letter edition

This edition reconstructs the standing sequence as a clean US Letter handout. It uses the book's original figure groupings and figure labels; the figures have not been redrawn or interpreted. The adjacent English is the source-faithful translation from the bilingual transcription.

## Print file

- `print/standing-sequence-constructed-letter.pdf` — 14 pages, US Letter portrait
- `previews/standing-sequence-constructed-letter-contact-sheet.jpg` — overview of all pages
- `print/pages/` — individual page PNGs

The bold breath line belongs to the numbered step below it. “Continue the same inhalation/exhalation without interruption” translates `吸气不停` / `呼气不停`; it does **not** introduce a breath hold.

The English text remains available with the exact Chinese source in `../standing-sequence-source-faithful/standing-sequence-bilingual.md`.

Rebuild from the project root with:

```sh
bash scripts/build_constructed_letter_standing.sh
```
